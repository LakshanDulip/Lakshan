00 · හැඳින්වීම

Git සහ GitHub යනු කුමක්ද?

Git

Git කියන්නේ ඔබේ පරිගණකයේ install කරගන්නා Version Control මෙවලමක්. එය ඔබේ code files වල වෙනස්කම් time-line එකක් විදිහට save කරගෙන යනවා — කවුරු, කවදා, මොනවද වෙනස් කළේ කියලා. Internet නැතුව වුණත් වැඩ කරන්න පුළුවන්.

GitHub

GitHub කියන්නේ Git repository ඔබට Cloud එකේ (Online) ගබඩා කරගන්න පුළුවන් වෙබ් අඩවියක්. ඔබේ code එක internet එකෙන් backup කරගන්න, වෙන අයට share කරන්න, සහ team එකක් එක්ක එකට වැඩ කරන්න GitHub උදව් වෙනවා.

💡 සරල analogy එකක්: Git = Microsoft Word වගේ මෘදුකාංගයක් (tool). GitHub = Google Drive වගේ, ඔබ හදන දේවල් online තියාගන්න තැනක්. Git එකෙන් "save" කරලා, GitHub වෙත "upload" කරනවා.

01 · Install

Git ඔබේ පරිගණකයට Install කිරීම

Git භාවිතා කරන්න පළමුව එය ඔබේ පරිගණකයට install කරගන්න ඕනේ. පහළ බටනය click කරලා ඔබේ Operating System එකට ගැලපෙන version එක download කරගන්න.

Git Download කරන්න (git-scm.com)

  1. Installer එක Run කරන්න

    Download වූ .exe file එක double-click කරන්න.

  2. Next, Next, Next...

    Setup wizard එකේ default settings ම තියාගෙන "Next" click කරගෙන යන්න. "Adjusting your PATH environment" කියන step එකේදී "Git from the command line and also from 3rd-party software" option එක තෝරාගෙන ඉන්න.

  3. Install ඉවර කරන්න

    "Install" click කරලා ඉවර වෙනකම් ඉන්න. පහුව "Finish" click කරන්න.

  1. ක්‍රමය 1: Installer

    Download වූ .pkg file එක open කරලා instructions follow කරන්න.

  2. ක්‍රමය 2: Homebrew (recommended)

    Terminal එක open කරලා පහත command එක run කරන්න:

    brew install git

  1. Ubuntu / Debian

    sudo apt update
sudo apt install git

  2. Fedora

    sudo dnf install git
✔ Verify කරන්න: Install වුණාද කියලා check කරන්න Terminal / Command Prompt එකේ මේක type කරන්න. version number එකක් පෙන්නනවා නම් install හරි.
git --version

02 · Install

VS Code Install කිරීම

Visual Studio Code (VS Code) කියන්නේ Microsoft සමාගමේ නොමිලේ code editor එකක්. එහි Git support built-in විදිහටම තියෙනවා, ඒ නිසා code ලියන එකත්, Git වැඩත් එකම තැනකින් කරගන්න පුළුවන්.

VS Code Download කරන්න

  1. Download කරන්න

    ඔබේ OS එකට ගැලපෙන installer එක download කරගන්න (Windows / Mac / Linux).

  2. Install කරන්න

    Windows නම් setup එකේදී "Add to PATH" සහ "Add 'Open with Code' action" checkbox දෙක select කරගෙන ඉන්න — ඒකෙන් පස්සේ folder එකක් මත right-click කරලා "Open with Code" කරන්න පුළුවන් වෙනවා.

  3. Extension එකක් දාගන්න (Recommended)

    VS Code එකේ වම් පැත්තේ Extensions icon එක click කරලා GitLens search කරලා install කරන්න — ඒකෙන් Git history එක visual ලෙස පෙන්නනවා.

03 · Setup

VS Code + Git සකස් කිරීම

  1. Terminal එක Open කරන්න

    VS Code එකේ Ctrl + ` (backtick key) press කරන්න — පහළින් Terminal එකක් open වෙනවා. ඔබේ ඉදිරි commands ටික මේකේ type කරන්න.

  2. ඔබේ Identity එක Git එකට කියන්න

    Commit කරන හැම වෙලාවකම "මේක කළේ මම" කියලා Git දැනගන්න ඕනේ. එක වතාවක් මේ දෙක run කරන්න (permanent ලෙස save වෙනවා):

    git config --global user.name "ඔබේ නම"
git config --global user.email "your-email@example.com"

  3. GitHub Account එකක් හදාගන්න

    නොමිලේ account එකක් හදාගන්න:

    GitHub Account හදන්න ↗

  4. VS Code එකට GitHub Login කරන්න

    වම් පැත්තේ Source Control icon එක (branch shape එක) click කරලා, පහළ වම් කෙළවරේ Accounts icon එකෙන් "Sign in with GitHub" තෝරන්න. Browser එකෙන් permission දීලා ආපහු එන්න.

04 · Core Commands

මූලික Git Commands

මේවා තමයි ඔබ දිනපතා පාවිච්චි කරන Git commands. Terminal එකේ type කරලා Enter press කරන්න.

ආරම්භයgit init

වත්මන් folder එක නව Git repository එකක් බවට පත් කරයි.

පරීක්ෂාවgit status

මොනවද අලුතින් හදලා තියෙන්නේ / වෙනස් කරලා තියෙන්නේ කියලා පෙන්වයි.

Stagegit add .

වෙනස් කළ files ඔක්කොම commit කිරීමට සූදානම් (staged) කරයි.

Savegit commit -m "..."

Staged වෙනස්කම් විස්තරයක් සමඟ permanent ලෙස Git history එකට save කරයි.

Historygit log

මේ දක්වා කරපු commits ලැයිස්තුව, කාලය සමඟ පෙන්වයි.

Copygit clone <url>

GitHub එකේ ඇති repository එකක් සම්පූර්ණයෙන්ම ඔබේ පරිගණකයට copy කරයි.

Uploadgit push

ඔබේ local commits GitHub වෙත upload කරයි.

Downloadgit pull

GitHub එකේ අලුතෙන් වෙනස් වූ දේ ඔබේ local repository එකට download කර ගනී.

💡 සරල workflow එකක්: Code වෙනස් කරන්න → git add . → git commit -m "message" → git push. මේ පේළි හතරම ඔබේ දෛනික ජීවිතේ බොහෝම වාරයක් type කරයි.

05 · Branches

Branches (අතු බෙදීම) යනු කුමක්ද?

Branch එකක් කියන්නේ ඔබේ code එකේ වෙනම පිටපතක්. එහෙනම් ප්‍රධාන code එකට (main) හානියක් නොවී, අලුත් feature එකක් අත්හදා බලන්න පුළුවන්. හැම දෙයක්ම හරි නම් විතරක් ඒක main branch එකට ආපහු එකතු (merge) කරගන්නවා.

Listgit branch

ඔබේ repository එකේ ඇති branches ලැයිස්තුව පෙන්වයි.

Creategit checkout -b new-feature

"new-feature" කියන නමින් අලුත් branch එකක් සාදා, ඒකට වහාම මාරු වේ.

Switchgit checkout main

ආපහු ප්‍රධාන (main) branch එකට මාරු වීමට.

Mergegit merge new-feature

"new-feature" branch එකේ වෙනස්කම් main branch එකට එකතු කරයි.

Deletegit branch -d new-feature

වැඩ ඉවර වූ, main එකට merge කළ branch එක මකා දමයි.

06 · Full Workflow

ඔබේ Project එක ප්‍රථම වතාවට GitHub වෙත Upload කිරීම

  1. GitHub වෙබ් අඩවියේ අලුත් Repository එකක් හදන්න

    github.com වෙත ගිහින් login වෙන්න, ඉහළ දකුණේ "+" → "New repository" click කරන්න. නමක් දීලා "Create repository" click කරන්න.

  2. VS Code Terminal එකේ Project එක Git වෙත සම්බන්ධ කරන්න

    ඔබේ project folder එකේ terminal open කරගෙන, පහත commands එකින් එක run කරන්න:

    git init
git add .
git commit -m "First commit"
git branch -M main

  3. GitHub Repository එකට Connect කරන්න

    GitHub එකේ repository page එකේ පෙන්නන URL එක copy කරගෙන:

    git remote add origin https://github.com/username/repo-name.git
git push -u origin main

  4. Refresh කරලා බලන්න

    GitHub page එක refresh කරන්න — ඔබේ files ඔක්කොම එහෙට upload වෙලා තියෙනවා දකින්න පුළුවන්! 🎉

07 · Collaboration

Pull Request (PR) එකක් යනු කුමක්ද?

Team එකක් එක්ක වැඩ කරද්දී, ඔබ කරන වෙනස්කම් කෙලින්ම main branch එකට දාන්නේ නෑ. ඒ වෙනුවට Pull Request එකක් හදලා, team එකේ අනිත් අයගේ අනුමැතිය ලබාගෙන පස්සේ merge කරනවා.

1. Branch එකක් හදන්න
→
2. GitHub වෙත Push කරන්න
→
3. "New Pull Request" open කරන්න
→
4. Review ඉල්ලන්න
→
5. Merge කරන්න

  1. Branch එකක් හදලා වෙනස්කම් කරන්න

    git checkout -b my-fix කරලා code වෙනස් කරන්න.

  2. GitHub වෙත Push කරන්න

    git push -u origin my-fix

  3. "Compare & pull request" Click කරන්න

    GitHub repository page එකට යනකොට, ඔබේ නව branch එක සම්බන්ධව එම බටනය automatic ලෙස පෙන්නනවා.

  4. විස්තරයක් ලියලා Submit කරන්න

    මොනවද වෙනස් කළේ කියලා කෙටියෙන් ලියන්න, පසුව "Create pull request" click කරන්න.

  5. Review වුණාට පස්සේ Merge කරන්න

    Team member කෙනෙක් approve කළාට පස්සේ, "Merge pull request" click කරලා ඔබේ වෙනස්කම් main එකට එකතු කරගන්න.

08 · Hosting

GitHub Pages — නොමිලේ Website Host කිරීම

ඔබ හදපු HTML/CSS/JS website එකක් සම්පූර්ණයෙන්ම නොමිලේ, GitHub Pages හරහා internet එකට live කරන්න පුළුවන්.

  1. Repository Settings වෙත යන්න

    ඔබේ GitHub repository එකේ ඉහළ "Settings" tab එක click කරන්න.

  2. Pages Section එක සොයන්න

    වම් පැත්තේ menu එකේ "Pages" click කරන්න.

  3. Branch එක තෝරන්න

    "Source" එකේ main branch එක තෝරලා "Save" click කරන්න.

  4. ඔබේ Site Live!

    විනාඩි කිහිපයකින් ඔබේ site එක https://username.github.io/repo-name ලෙස internet එකේ live වෙනවා.

09 · Quick Reference

Git Cheat Sheet

Commandවිස්තරය
git initනව repository එකක් ආරම්භ කරයි
git clone <url>Remote repository එකක් copy කරයි
git statusවත්මන් වෙනස්කම් තත්ත්වය පෙන්වයි
git add .සියලුම වෙනස්කම් stage කරයි
git add <file>නිශ්චිත file එකක් පමණක් stage කරයි
git commit -m "..."Staged වෙනස්කම් save කරයි
git pushLocal commits GitHub වෙත යවයි
git pullGitHub එකේ අලුත් වෙනස්කම් ලබාගනී
git logCommit history එක පෙන්වයි
git branchසියලුම branches ලැයිස්තුව
git checkout -b <name>නව branch එකක් හදලා මාරු වේ
git checkout <name>වෙනත් branch එකකට මාරු වේ
git merge <name>Branch එකක් වත්මන් branch එකට එකතු කරයි
git branch -d <name>Branch එකක් මකා දමයි
git remote add origin <url>Local repo එක GitHub URL එකකට සම්බන්ධ කරයි
git remote -vසම්බන්ධිත remote URLs පෙන්වයි
git diffLine by line වෙනස්කම් පෙන්වයි
git stashවෙනස්කම් තාවකාලිකව side එකකට තියාගනී

❤ සිංහලෙන් නිර්මාණය කරන ලදී — ඉගෙන ගැනීම කවදාවත් නවත්තන්න එපා!
