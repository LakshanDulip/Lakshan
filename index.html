🚀 GitHub කෙටි පාඨමාලාව

මුල සිට සරලව සිංහලෙන් - Lakshan විසින් නිර්මාණය කරන ලදී

උපදෙස්: පාඩමක් අවසන් කළ පසු එය මත Click කරන්න.

1. මූලික කමාන්ඩ්ස් (Basic Commands)

පරිගණකයේ කෝඩ් GitHub එකට යැවීමට git add ., git commit -m "massage" සහ git push භාවිතා කරයි.

2. අන්තර්ජාලයෙන් ගැනීම (Pull)

වෙනත් අයෙක් හෝ වෙනත් පරිගණකයකින් කළ වෙනස්කම් තමන්ගේ පරිගණකයට ගැනීමට git pull භාවිතා කරයි.

3. Branches (අතු බෙදීම)

ප්‍රධාන කෝඩ් එකට හානියක් නොකර අලුත් දේවල් අත්හදා බැලීමට git checkout -b branch-name මගින් අලුත් අත්තක් සාදාගනී.

4. Pull Requests (PR)

වෙනත් Branch එකක කළ වෙනස්කම් ප්‍රධාන කෝඩ් එකට (main) එකතු කිරීමට පෙර අනුමැතිය ලබා ගැනීමට PR එකක් සාදයි.

5. GitHub Pages (Hosting)

තමන් සෑදූ HTML, CSS, JS වෙබ් අඩවියක් සම්පූර්ණයෙන්ම නොමිලේ අන්තර්ජාලයට (Live) එකතු කිරීමට මෙය භාවිතා කරයි.
